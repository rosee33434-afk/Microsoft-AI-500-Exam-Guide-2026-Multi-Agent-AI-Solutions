## 5 Demo Practice Questions

**1. Which protocol standardizes connections between AI applications and external tools?**
- A. MCP
- B. SMTP
- C. FTP
- D. DHCP

**Answer:** A — MCP.

**2. What is the main purpose of RAG?**
- A. Increase network bandwidth
- B. Ground responses in retrieved information
- C. Replace all AI models
- D. Manage user passwords

**Answer:** B — Ground responses in retrieved information.

**3. What helps investigate latency across a multi-agent workflow?**
- A. Removing logs
- B. Disabling monitoring
- C. Distributed tracing
- D. Increasing prompt length

**Answer:** C — Distributed tracing.

**4. Which approach supports least-privilege access to Azure resources?**
- A. Shared administrator passwords
- B. Public access for all agents
- C. Hardcoded credentials
- D. Managed identity with scoped permissions

**Answer:** D — Managed identity with scoped permissions.

**5. What is a key benefit of assigning distinct roles to agents?**
- A. Clear task responsibilities and workflow coordination
- B. Eliminating all testing
- C. Removing security controls
- D. Preventing tool integration

**Answer:** A — Clear task responsibilities and workflow coordination.
